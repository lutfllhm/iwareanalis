🚀 CARA DEPLOY (3 LANGKAH)

STEP 1: EDIT KONFIGURASI (2 menit)
────────────────────────────────────────────────────────────────
   File: .env.production
   
   Ubah ini:
   ✎ DB_PASSWORD=password_kuat_anda
   ✎ DB_ROOT_PASSWORD=root_password_kuat
   ✎ JWT_ACCESS_SECRET=random_32_karakter_atau_lebih
   ✎ JWT_REFRESH_SECRET=random_lain_32_karakter
   ✎ ACCURATE_REDIRECT_URI=http://IP_VPS:3010/settings
   ✎ NEXT_PUBLIC_API_URL=http://IP_VPS:5010/api

STEP 2: UPLOAD KE VPS (2 menit)
────────────────────────────────────────────────────────────────
   Pilih salah satu:
   
   A. Via WinSCP (GUI - Termudah)
      1. Download: winscp.net
      2. Connect ke VPS
      3. Drag folder ke /opt/
   
   B. Via Command Line
      scp -r dataanalis/ user@vps-ip:/opt/
   
   C. Via Git
      git push origin main
      ssh user@vps-ip
      cd /opt && git clone repo-url dataanalis

STEP 3: DEPLOY! (1 menit)
────────────────────────────────────────────────────────────────
   ssh user@vps-ip
   cd /opt/dataanalis
   chmod +x *.sh
   ./deploy.sh

   ✅ DONE! Akses: http://vps-ip:3010
